# Hacking Ético (Blue Team focus)

Notas de estudo a partir do curso de Ethical Hacking / Pentest, com
recorte nos módulos mais úteis para detecção e resposta (Blue Team):
reconhecimento, engenharia social, exploração de rede/wifi e
pós-exploração. Módulos de planejamento contratual, exploração de
aplicações web, cloud/mobile/IoT, ferramentas/scripting e relatório de
pentest não entram neste recorte.

`blue-team-lab/` (Wazuh) e ao `pcap-analysis/`.
