# Dark Web — O que Todo Analista Deveria Saber

**Equívoco 1 — "Não acesso a dark web, então não me afeta":** falso. A dark web é onde dados vazados (e-mails, senhas, dados financeiros) costumam ser comercializados. Se uma empresa sofre uma violação, dados de clientes podem acabar lá — mesmo que o usuário nunca tenha acessado a dark web.

**Equívoco 2 — "É só para criminosos":** para fins defensivos, o que importa é que dados vazados circulam lá, inclusive credenciais corporativas. Monitoramento de dark web (dark web monitoring) é uma prática usada por times de segurança para detectar se credenciais da própria organização apareceram em vazamentos.

**Conexão com reutilização de senha:** uma violação em um serviço pode comprometer todas as contas que usam a mesma senha — reforça por que políticas de senha única por conta e 2FA são controles tão recorrentes em qualquer checklist de segurança.

**Boas práticas de proteção (nível usuário/organização):**
- Senhas fortes e únicas por conta (idealmente com gerenciador de senhas)
- Autenticação de dois fatores sempre que disponível
- Monitorar contas/credenciais quanto a sinais de comprometimento
- Evitar sites de pirataria — vetor comum de malware que pode redirecionar a infraestrutura maliciosa
